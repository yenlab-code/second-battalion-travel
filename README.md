# 二大差旅費

保六總隊第二大隊國內差旅申報規定與初核工作台。

公開網站：<https://yenlab-code.github.io/second-battalion-travel/>

## 功能

- 先確認核派、日期行程、出差必要性及實際服務駐地，再判斷案件性質。
- 案型與試算連動：一般公務可依條件列計交通、住宿、雜費；上課或特定活動只先列臺鐵實付，其他交通與自駕列為待認定且不計入總額；其他特殊案件停用一般試算。
- 去程、回程逐段記錄大眾運輸；常用路線只作為填寫範本，每段都需人工核對。
- 自駕依去回程必要里程計算，且必須確認申報人為實際駕駛。
- 住宿與雜費可逐日新增、分別判斷並加總，支援多日案件。
- 自動彙整案型、可列金額、缺件與待認定事項，可列印或下載文字摘要。
- 附件分為「依法必附」、「內規要求」與「承辦佐證」。
- 29則白話規定附例子與依據；常用規定優先呈現，其餘依主題收合。
- 交通費區提供臺鐵、北捷、臺北公車及臺中公車官方票價查詢入口。
- 手機版將每一個交通路段改為直向表單，方便逐段填寫。

## 使用

直接開啟 `index.html`。所有輸入只在目前瀏覽器頁面計算，重新整理後會清除。

公開網站不嵌入或連結保六內規及彙編 PDF 全文，只呈現整理後的摘要、例子與條號。內部原始文件應留在共用資料夾或離線 ZIP，不應放入公開儲存庫。

## 維護

規定卡片位於 `tools/build.py`；畫面與互動邏輯位於 `tools/template.html`。更新後執行：

```text
python tools/build.py
node tools/check.cjs
```

`index.html` 是生成後的發布檔。更新網站時應同時提交 `index.html`、`README.md`、`tools/build.py`、`tools/template.html` 與 `tools/check.cjs`。

後續使用者要求修改時，完成內容調整、法規核對與測試後，直接同步 GitHub Pages。不設每月自動法規更新，也不自行改動核銷標準。

## 存取與發布

GitHub 儲存庫：`yenlab-code/second-battalion-travel`（公開）。GitHub Pages 從 `main` 分支根目錄發布。

HTML 中的 `noindex` 只降低搜尋引擎索引機會，不限制持有網址的人存取。
