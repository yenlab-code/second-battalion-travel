# 二大差旅費

保六總隊第二大隊國內差旅申報規定與審查工作台。內部使用，請保持儲存庫私有。

## 使用

下載整個專案後開啟 `index.html`。單一 HTML 已包含規定摘要、保六內規全文、64頁彙編文字及北捷票價快照；PDF原件連結需要保留 `sources` 資料夾。票價即時讀取與外部查詢需要網路。

## 內容

- 六步審查 SOP、送件勾選表。
- 29則白話規定，每則附實際例子與依據，明確區分內規、中央規定與待主計確認事項。
- 兩條常用行程、去回程分開計算、自駕來回里程試算、大眾運輸分段加總及 CSV 匯出。
- 北捷官方票價查詢（1150830快照，含限期優惠，超出期間不套用），可嘗試更新官方資料；臺鐵自強號及公車提供官方查詢入口。
- 住宿與雜費單日初核、115年3月彙編全文搜尋。

介面採霧粉、淡櫻花粉、柔白與灰紫色系；官方臺鐵、北捷、臺北公車及臺中公車查詢入口已放在交通費工作表旁，方便查價後返回填寫。

法規查核日：2026-09-23。保六內規為使用者提供的114年1月1日生效版本；無法由公開網路證明沒有後續內部函示。未判明之「火車票價」車種、接駁、自駕限制及免附憑證事宜已標示待主計確認。

## 維護

編輯 `tools/build.py` 的規則卡與 `tools/template.html` 的畫面、計算邏輯，再執行：

```text
python -m pip install pypdf
python tools/build.py
node tools/check.cjs
```

`index.html` 是生成後的正式成品；發布時應同時部署 `index.html` 和 `sources/`。不要把 `tools/` 或其他研究中間檔當作公開網站路徑。

後續使用者要求修改時：修改、核對法規與相關計算、更新版本說明、驗證畫面，提交此私有庫並同步更新受登入保護的網站。**不設每月自動法規更新，也不自行改動核銷標準。**

## 存取與發布

GitHub儲存庫：`yenlab-code/second-battalion-travel`（私有）。一般 GitHub Pages 不提供個人帳號私密網站存取控制，因此不啟用公開 Pages。需另由有登入保護的網站服務發布並設定內部人員白名單。未完成發布前，GitHub檔案存放不等同網站已上線。

所有計算在瀏覽器執行，工作表不會上傳。輸入內容於重新整理後清除。HTML中的 `noindex` 只防搜尋索引，**不是存取保護**；部署端必須真正驗證訪客權限。
